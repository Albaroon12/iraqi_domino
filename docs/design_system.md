## 2. التشريح الهندسي للمكونات (Component Geometry)

1. **الزر الرئيسي (`MaqhaGoldPillButton` — `العب الآن ◀`)**:
   - شكل كبسولة كاملة (`borderRadius: 999`)، ارتفاع `56–60px`، تدرج عمودي `#F7CB62 → #E7BB50 → #D6AD41` مع توهج خارجي ناعم وسهم تشغيل يتجه لليسار مع اتجاه القراءة العربي.
2. **بطاقات اللعب الأربع (`MaqhaModeCard`)**:
   - مستطيل داكن (`#182022`) بزوايا دائرية `16px` وحد رفيع `1px`، يتوسطه عمودياً: أيقونة ذهبية (`26px`) ← عنوان أبيض عريض (`14.5px`) ← وصف رمادي هادئ (`11px`).
3. **شريط الأدوات العلوي**:
   - جهة اليمين: كبسولة اللاعب الدائرية (`MaqhaPlayerIdentityPill`) تعرض الاسم واللقب ودائرة الأفاتار الخضراء بحلقة ذهبية.
   - جهة اليسار: كبسولة رصيد الدنانير الذهبية + صف أزرار مربعة بزوايا ناعمة (`38×38px`, `radius: 11px`) للإشعارات والأصدقاء والحماية والإعدادات.
4. **شريط التنقل الزجاجي العائم (`Floating Capsule Dock`)**:
   - كبسولة داكنة مستقلة بحواف دائرية كاملة (`radius: 26px`) بدل الشريط السفلي الملتصق التقليدي، تضم (`القاعة`، `المهام/البطولات`، `السوق`، `المتصدرون`، `ملفي`).
5. **كبسولة المكافآت السريعة الجانبية**:
   - كبسولة صغيرة عمودية تضم زر الهدية اليومية `🎁` وزر المهام اليومية `✓`.
